# CoinFT 六维相对趋势演示

目标：在单台 Windows 电脑上，访问本地浏览器页面，通过 Teensy COM10 显示一个 CoinFT 的六维变化及 12 路原始变化。支持已采集 CSV 回放，便于无硬件时排练。

数据流：Teensy 26 字节帧 → Python 严格帧解析 → 首 2 秒空载均值作为本地基线 → 历史矩阵投影到 Fx/Fy/Fz/Mx/My/Mz 六个相对趋势 → 本地 HTTP JSON → 浏览器图表。仅发送 `i`/`s` 控制串口流，不下发 `t` 调参，也不向 CoinFT 写入标定值。

界面：深色仪器风格，中央六维响应图、六张趋势卡、12 路原始响应条、数据源与采样率状态。方向趋势无物理单位；页面持续显示“未标定”。回放始终显示“历史回放”。显示灵敏度只控制图形比例。

验收：碎片化帧、错位帧解析测试；零点投影测试；历史 CSV 回放的 HTTP API 和页面截图；若 COM10 未枚举则报告硬件验收待做。避免任何强制刷新后自动将回放改成实时。

官方代码只用于核对协议/交互形态；本演示代码独立实现。官方模型属于 CFT24 专属标定，且仓库声明 CC BY-NC-SA 4.0，此演示不复制其实现或模型。
