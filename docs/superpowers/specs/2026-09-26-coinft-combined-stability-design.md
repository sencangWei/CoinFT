# 定性正压＋剪切稳定显示

操作者已批准：只调整定性演示剪切的平滑、启停滞回和适度显示增益，不改原趋势页/原始数据/采集参数，不靠正压伪造剪切。

实测组合5.09秒：正压目标恒为1，近期异常/饱和0；剪切投影中位93.45counts，启动门槛99.11，45快照中24次被截为零。现象可由当前门槛切换复现，但不宣称传感器六维物理标定通过。

设计：仅定性模式对有符号剪切投影先按画面满幅限幅：边界为max(原启动门槛,0.6×原门槛+0.85×span)，再做180ms时间常数EMA；保留原启动门槛，同向退出门槛为原门槛60%，反向须重新越过原启动门槛。启用后幅度以(绝对投影−退出门槛)/(0.85×span)显示并限幅。每个画面独立保存滤波状态，clear/异常/禁用/换模板立即清状态。法向与严格模式保持原计算，网格几何不改。零输入/强反向应在当前真实模板及测试模板的常见100ms更新节奏下600ms内归零/正确反向，不无限保持。用户已另行批准“过量显示信号先限幅再平滑”，覆盖原无界EMA定义；共享原始投影、原始数据与严格模式不得限幅。其他任意极端门槛/span比的模板不在本时限保证范围。

验收：精确非饱和幅度、空载不起动、组合双分量、反向启动门槛、释放/清屏/错误门禁、严格模式数值不变及原几何检查；真实采样离线回放零窗比例/抖动下降。离线通过不等于新实机动作已验收；部署后需操作者逐步确认。
