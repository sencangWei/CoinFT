# CoinFT 定性演示：短暂异常自动恢复

用户已明确要求：演示中短暂异常恢复后动画自己恢复，不应反复点归零。本规格覆盖旧定性规格的“任意异常均清基线”条款；严格验收模式不变。

## 行为

1. 一次成功的演示归零仍由操作者在空载下明确触发。采集从第一帧有效数据起跨度至少 1000 ms、至少 10 个递增有效快照；不能带载自动估计基线。
2. 已完成基线遇到异常帧计数、饱和、短暂等待、HTTP 错误/超时、坏通道或 500 ms 停滞时，立即清形变并标注暂停/等待自动恢复，保留基线。
3. 只有新的健康递增帧（12 路有限值、近期异常/饱和为零）才能恢复；不能拿重复旧帧维持或重新开启形变。恢复后原样复用基线，按当前信号显示，不偷偷归零。
4. 未完成的归零遇到故障仍取消采样；不能自动继续拼接两段空载。
5. 真正设备去皮/已观察到的 taring、帧序倒退或明确发现采集偏置改变时必须使基线失效，避免用错偏置。临时清屏不能抹掉帧号连续性检查。服务重启后应在未归零状态可重新归零。

## 边界

只改前端生命周期和浏览器回归测试，不改固件、串口参数、模板、阈值、网格形变或趋势页。真正去皮与重连偏置不是短暂坏帧；没有有效数据时画面不能伪造持续变形。现有后端不发布独立去皮序号，跨长时间网络失联时漏看 taring 的偏置连续性须在复核中明确评估，不可夸大成硬件已验收。

## 验收

隔离浏览器测试验证“加载动画→坏数据/断流时清平→新的好帧后自行恢复”，保留非零基线完全一致且无 POST tare；重复帧不恢复、去皮与倒退仍失效、未完成归零仍取消、严格模式和原几何测试通过。实际设备故障未现场触发时，报告仅称自动化故障注入通过，不称所有实机断连根因已消除。
