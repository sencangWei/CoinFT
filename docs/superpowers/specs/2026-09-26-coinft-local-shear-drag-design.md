# CoinFT A 型局部剪切拖拽显示

日期：2026-09-26。视觉选项已由操作者回复 A，并在预览页面选择 local-drag；操作者随后回复“开始”，批准本书面规格并开始实现。

## 视觉目标

- 采用已选择的预览 A：中部被沿剪切方向拖动，外围位移连续减小，外缘不随之整块移动。网格线弯曲并出现疏密变化，不是平面整体倾斜。
- 正压仍显示中心凹陷；正压与剪切同时存在时，凹陷随中部拖拽偏移。纯剪切无需正压也能显示拖弯与局部起伏。
- −X 对应画面向右、+X 对应画面向左。反向输入产生镜像形变，松开回到原网格。
- 无独立时间驱动的水波、持续流动或随机动画；画面只跟随现有信号强度及现有平滑过渡。

## 绘图映射

沿用当前归一化网格坐标 u,v ∈ [-1,1]、法向强度 p ∈ [0,1]、带符号剪切 s ∈ [-1,1]。

- 包络 E = ((1-u²)(1-v²))²，外缘为 0，中部最大。
- 材料平面坐标变为 u' = u + 0.44sE，v' = v − 0.44sE。当前投影的屏幕横向取 u'−v'，故正 s 向右；不用整体平移或线性倾斜模拟剪切。
- 法向凹陷包络中心沿 (0.19s,−0.19s) 移动；s=0 时保留原法向凹陷位置、宽度与幅度。
- 剪切局部高度项取 0.19s(u−v)E，以小幅连续起伏辅助表达拖弯，不把整个面变成斜平面。
- 颜色强度综合法向凹陷包络及 |s|E，限制在 [0,1]；纯剪切也有局部色块响应。
- 所有系数均为显示用，不是力学标定或位移单位。

## 生命周期

复用现有 requestAnimationFrame 平滑、clear、resize 与 reduced-motion。空载/断流/坏数据的清空由原门禁驱动，不保留旧形变；正常重复快照跳过的修正规则不变。

## 验证与停止条件

1. 固定模拟输入对比截图：空载、纯正压、左右纯剪切、正压叠加剪切、释放；与已选 A 预览的非均匀拖弯形态一致，保持生产布局。
2. 几何测试：外缘不动、内部位移非均匀且方向正确、剪切使线条非共线、相反符号镜像、满幅网格单元在材料坐标中不翻折且非相邻网格线不相交、输入为零回原平面。**2026-09-26 操作者回复“保留”批准修正：保留原正压深凹陷，不要求三维高度场投影后的每个三角形都与平面同向**；旧正压已有投影反向，这与材料网格折叠不同。测试从实际绘图顶点去除约定高度项并逆投影，检查材料坐标，不只测试重复的位移公式。
3. 浏览器及全套回归：原正压响应、方向计算、归零/断流门禁、趋势/通道内容、resize 与 reduced-motion 均保持；检查 JS 错误。
4. 合成输入仅用于离线验收，不能注入实时页面伪装成传感器动作。实际页面刷新会丢失页面基线，刷新后须操作者空载确认并点演示归零，不自动带载归零。
5. 生产改动完成且测试通过后打开实时页面供操作者确认。左右动作方向仍需实际验证；视觉选 A 不等于传感器方向独立验收通过。
